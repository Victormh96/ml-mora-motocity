# Predicción de mora en créditos de motos – Motocity

Proyecto de Machine Learning para la asignatura Inteligencia Artificial (MGETI – UFG, ciclo 02-2026).

- `creditos_motocity.csv`: dataset simulado de 1,012 créditos con estructura tipo SAP Business One (no contiene datos reales de clientes).
- `generar_dataset.py`: script con el que se generó el dataset.
- `Tarea_ML_Mora_Motocity.ipynb`: notebook de Google Colab con el análisis completo.
